# L0 · 约束确认：0.5B 到底意味着什么

> 02 阶段第一步。产出 = 后面所有设计的"宪法"。
> 方法：每个约束写清 **值 + 来源 + 为什么 + 会约束住什么**。
> 以后 L1/L2 里任何一个决定，违反这里的约束就是无效决定。

## 1. 为什么是 0.5B（不是 100M，也不是 7B）

参数规模是第一个分叉口。判断锚点不是"越大越好"，是**迭代成本**：
我们要反复换人格/换工具重训（"性格实验自由"），单次训练时长必须可接受。

| 规模 | 2×4090 上训 1.5B token（粗估） | 换一版人格重训 | 能力 | 结论 |
|---|---|---|---|---|
| ~100M | 3~6 小时 | 一天能试好几版 | 工具格式都勉强，性格撑不起来 | 太小 |
| **~500M** | **15~28 小时（见 03 估算）** | **一周一两版，可行** | **人格 + 2~4 工具 + 轻量推理** | ✅ 选它 |
| ~7B | 数周起，且 1.5B token 对 7B 严重欠训练 | 一次迭代按月上计 | 接近通用 | 迭代太慢，杀性格实验 |

> 定性结论：我们是**定位清晰的小智能体**（人格陪伴 / 少工具 / 轻推理），
> 不是通用模型 → 0.5B 是甜点。定量推导（参数量↔显存↔速度公式）L2 补上。

**"0.5B"的容差**：450M~550M 都算达标。B 不是小数点精确的承诺，
是"这个量级"。L2 审计时看偏差 < 10% 即可（验收写 <2% 是相对最终拍板值）。

## 2. 0.5B 翻译出来的四条硬约束

| # | 约束 | 值 | 来源 | 会约束住什么 |
|---|---|---|---|---|
| C1 | 参数预算 | **450M~550M** | 项目目标（本阶段要设计的对象） | L2 的"总盘子"：hidden、层数、头数、中间维度全从这个数里分，加起来不能超过 |
| C2 | 训练硬件 | 2× RTX 4090（24G×2），bf16 全参 DDP | 00_env 侦察 | 宽度和深度不能太夸张：权重+梯度+优化器状态+激活必须装进 24G×2。粗算：500M 参数 bf16 权重 1G + 梯度 1G + AdamW(fp32 母本+m+v) 6G ≈ 8G/卡，剩 16G 给激活和通信 → seq 512~1024 宽裕 |
| C3 | 词表 | **6400（锁死，不许改）** | 01_tokenizer 训好的 BPE，语料已按它编码 | embedding 参数 = 6400 × hidden，是 C1 的一块固定支出；hidden 越大这块越贵 → 影响 L2 里 hidden 的上限 |
| C4 | 上下文 | 32768 | Qwen3 风格，RoPE；以后可 YaRN 扩 | RoPE 几乎零参数成本（只多一个 θ 表），选它基本白拿长上下文能力 |

## 3. 底座架构（不重造轮子）

继承 minimind 的 **Qwen3 风格 decoder-only Transformer**，我们只做两件事：
**选组件（L1）+ 分参数（L2）**。

- 为什么 decoder-only：pretrain 目标是 next-token prediction，
  03 预训练 / 04 SFT / 06 agent 全链路都是这一个目标，没有理由上 encoder/enc-dec。
- 为什么继承 minimind 而不是自研：代码已验证能跑，我们的目标是学会
  **"怎么设计"**（约束→选择→分配→验证），不是发明新架构。
  自研留给学完这一遍之后（E3 mini GPT 算半个）。

## 下一步 → L1 骨架选择

六个组件逐个拍板，每个都写"选了它 + 为什么 + 落选的替代方案"：
1. 注意力类型：MHA / **GQA** / MQA
2. 位置编码：RoPE / 绝对位置 / ALiBi
3. 归一化：RMSNorm(pre-norm) / LayerNorm
4. FFN：SwiGLU / GELU
5. embedding 与 lm_head 是否共享（tie）
6. dropout 等训练技巧（0.5B 下基本全关）
