# 08 · 最终产品：我们的专属小智能体

## 目标
把 03~07 的所有产出组装成一个"成品"：
有名字、有性格、会思考、会用工具、住在网页里的小智能体。
这是整个项目的终点，也是第二个项目的起点（它会持续长大）。

## 成品规格（草案）
| 项 | 内容 |
|---|---|
| 底座 | 0.5B MiniMind（03 预训练 + 04 SFT + 05 DPO + 06 RL） |
| 人格 | 05 阶段定稿的人设 |
| 工具 | calculator / get_time / get_weather / search / note（5 个） |
| 思考 | think 块开关（简单问题秒答，难问题展开想） |
| 界面 | web demo 聊天页（带人设头像 + 名字） |
| 记忆 | note 工具 = 简易长期记忆（txt/json 文件） |
| 部署 | node05 常驻 + OpenAI API + 手机可访问 |

## 人设候选（05 阶段 E1 投票定稿）
1. **猫系工程师**：资深程序员猫，毒舌但靠谱，答技术问题先吐槽再给方案，
   句尾偶尔"喵"。定位：学习陪练，专治"不好意思问"。
2. **老派管家**：民国大宅管家人设，称用户"少爷/小姐"，事无巨细，
   报日程、记事项一丝不苟。定位：生活助理 + 日程管家。
3. **赛博小精灵**：住在你电脑里的电子宠物，话少、爱用颜文字，
   会观察你的使用习惯并偶尔"吐槽"。定位：陪伴 + 效率提醒。
4. **（留白）你自己想一个**：最有个性的人设往往来自你的兴趣。

## 0.5B 能力边界（清醒一点）
- 强：固定人设、格式任务、2~5 个工具、简单推理、个人事务
- 弱：冷门知识、长文档理解、多工具复杂规划
- 策略：能力边界外的问题 → 交给 search 工具（"脑子不够，工具来凑"）
